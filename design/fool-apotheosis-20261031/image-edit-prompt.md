# 普通面容修订

编辑这张已选中的《诡秘之主》“神诞”插画，保持原图横向16:9比例、人物位于右侧、左侧大面积低对比灰雾留白、空无斗篷、半透明面具、银灰与少量旧金配色、光线、服装细节、构图和画风。不要重新设计场景。本次只重点修改克莱恩的面貌，用户明确说他不是很帅的人。

把现在像俊美偶像/精致男模的脸，改成普通的、瘦削而疲惫的青年男性，有朴素书卷气，二十多岁，黑色短发有些凌乱，褐色眼睛。眼睛略小一些、眼神内敛而坚定，眼睑有一点倦意，眉形自然平直，不做凌厉的漂亮眉眼。鼻梁自然普通、鼻头略圆，不要极高鼻梁；颧骨不突出，下颌不做雕塑般尖锐线条，薄唇自然、表情平静。脸部比例真实些，保留少量不完美与生活感，不要美颜、不要发光白皙无瑕皮肤，不要魅惑眼妆，不要帅气微笑。也不要故意画丑、老化成中年、夸张眼袋、脏乱伤疤或滑稽化。普通长相中呈现清醒、疲惫、坚韧以及成神后的遥远感。

与脸相邻的半透明面具仍是同一张脸的成形残影，调整为相同的普通五官，不新增另一个人。神性来自空无的斗篷、灰雾与整体气势，不靠俊美。其他部分最大限度保留不变。无文字、logo、水印、边框、UI。
