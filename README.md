## 桌面集成

使用本机 DSH 原生 React 设置插槽和主题令牌接口。插件在设置通用页提供十个图片按钮，以及右上方的内容清晰度和关闭图标。首次安装默认关闭；选中后保存本机偏好。十个序列均有静音视频：戴莉渐散后停留于尾帧，切换出去再选回来才重播；其余九段循环播放。加载及播放失败时显示对应静态图。切换序列会释放旧播放器，后台暂停、回到窗口继续，清晰度切换不重启视频。1.1.0 已替换序列3/4/5，媒体地址带版本号以更新旧缓存。见[本次替换记录](docs/scene-update-2026-10-30.md)。

背景与图标由 Host 的五十三条固定 `/api/lotm-sequence-atlas/assets/` 路由提供：十套活动 WebP 原图和缩略图、保留的小丑旧图及其缩略图、三张透明装饰、十八枚 SVG 图标及十段 MP4，无外部媒体服务。五深五浅，每套有独立代码底色，主操作与导航辅色分开；六套局部雾光渐变，其他保持平整。代码/执行区不使用装饰渐变，保留终端 ANSI 色彩。

1.2.0 采用用户选定的第一套墨绿旧金视觉，十个主题分别配色。品牌与欢迎标题用宋体，正文用系统中文字体，代码保持等宽。侧栏导航行高32px，塔罗会按钮35px，秘偶使用双面戏剧面具。品牌眼纹、淡色眼纹水印和输入框刻饰来自生成的透明PNG；图标统一使用Tabler Outline。正文、代码块、执行结果及输入框保持同一中轴，滚动槽对称占位。速度、缓存率和上下文读数定位到顶部页签右侧，窗口不足时回到原位置。左右分界为贯穿内容区的低调细柱。

主题启用时，“新会话”改为“塔罗会”，“插件”改为“封印物”，“自动化任务”改为“秘偶”，“任务看板”改为“亵渎石板”，“工作区”标题改为“成神途径”，欢迎标题改为“欢迎来到诡秘世界”，通用输入占位提示改为“我有一个任务要发布”。这些替换限定在原生导航和占位提示，保留原按钮、编辑器内容、用户会话标题及消息。关闭主题后恢复原有文案。见[界面更新记录](docs/ui-update-2026-10-31.md)。

关闭或卸载时清理插件自己的令牌、样式和背景层，恢复启用前的宿主明暗偏好；点击 Gradually 风格时主动交还控制。不会修改旧插件文件或存储键。

## 开发与验证

使用 Node.js 18 以上。`npm run build` 构建 `lib/`；`npm test` 验证状态、对比度、资源路由和客户端生命周期；`npm run check` 检查产物语法。安装目标为 `%USERPROFILE%\.dsh\profiles\desktop`，不是网页服务。

图片源稿保存在 `design/`，插件实际资产及溯源记录在 `assets/`。图片为同人生成素材，角色与作品权利归原权利人；不附带官方授权。

图标采用 [Tabler Icons](https://github.com/tabler/tabler-icons) Outline，作者Paweł Kuna及贡献者，按MIT许可使用。原始SVG、固定版本来源与许可分别保存在 `assets/icons/tabler/original/`、`sources.json` 和 `LICENSE`，见 `THIRD-PARTY-NOTICES.md`。
