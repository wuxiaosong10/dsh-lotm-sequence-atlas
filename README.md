## 桌面集成

使用本机 DSH 原生 React 设置插槽和主题令牌接口。插件在设置通用页提供十个图片按钮，以及右上方的内容清晰度和关闭图标。首次安装默认关闭；选中后保存本机偏好。当前交付为静态背景，没有视频或眨眼动画。

背景由 Host 的二十三条固定 `/api/lotm-sequence-atlas/assets/` 路由提供：十套活动 WebP 原图和缩略图、保留的小丑旧图及其缩略图、一张透明细柱，无外部图片服务。六深四浅，每套有独立代码底色，主操作与导航辅色分开；六套局部雾光渐变，其他保持平整。代码/执行区不使用装饰渐变，保留终端 ANSI 色彩。

侧栏采用 Gradually 的紧凑分组结构：完整的图标＋新会话按钮（14px 加号）、导航、工作区和会话行。正文、代码块、执行结果及输入框统一最大宽度并居中，滚动槽对称占位。速度、缓存率和上下文读数定位到顶部页签右侧，窗口不足时回到原位置。左右分界为低调细柱，已取消早期宝座门头装饰。

关闭或卸载时清理插件自己的令牌、样式和背景层，恢复启用前的宿主明暗偏好；点击 Gradually 风格时主动交还控制。不会修改旧插件文件或存储键。

## 开发与验证

使用 Node.js 18 以上。`npm run build` 构建 `lib/`；`npm test` 验证状态、对比度、资源路由和客户端生命周期；`npm run check` 检查产物语法。安装目标为 `%USERPROFILE%\.dsh\profiles\desktop`，不是网页服务。

图片源稿保存在 `design/`，插件实际资产及溯源记录在 `assets/`。图片为同人生成素材，角色与作品权利归原权利人；不附带官方授权。

图标采用 [Lucide](https://lucide.dev/) Power、Contrast 的线条几何，按 ISC 许可使用，见 `THIRD-PARTY-NOTICES.md`。
